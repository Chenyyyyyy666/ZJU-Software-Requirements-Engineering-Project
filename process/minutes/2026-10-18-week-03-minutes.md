### 2.3 接口与测试边界

- Memory schema 版本保持 `0.1`，来源键统一为 `(session_id, turn_id)`。
- 检索只返回候选，不在检索层删除旧状态；是否有效留给 Query 分析和状态解析判断。
- 测试编码器和 Mock 响应只用于契约测试，不能代替真实语义抽取质量。

## 3. 复盘结论

- 继续采用“接口先行、模块独立”的方式：Memory 模块只提供可追溯数据，动态判断和答案生成放在推理模块。
- 真实 DeepSeek 抽取质量尚未验证，因此不能把 Mock 测试通过写成功能效果已完成。
- Web 和评测必须复用同一条问答流水线，不能在前端或评测脚本中重新实现状态判断。
- 跨平台验证目前只覆盖部分环境，macOS 与团队统一 Python 版本仍需验收。
